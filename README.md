# ML Algorithms From Scratch 🧠

A self-guided question book for learning machine learning by implementing
every algorithm from scratch. Each chapter is a folder. Each folder's
README is your question sheet.

> **Recommended order vs hard prerequisites.** The table above lists chapters
> in the recommended learning order (1 → 7). The "Hard Prerequisites" column
> lists the concepts and chapters you **must** understand before starting. The
> "Recommended After" column shows which chapters give you useful context but
> are not strictly required. Chapters 4, 5, and 6 can be studied in any order
> once their hard prerequisites are met.

## How to Use This Repo

1. Open the chapter `README.md` — it is your question sheet.
2. Answer the conceptual questions **in your own words** before writing any code.
3. Complete the mathematical derivations **by hand**.
4. Implement each algorithm from scratch in a `.py` file inside the chapter folder.
5. Work through the edge cases and write your own tests.
6. Check off each item when you're satisfied with your understanding.
7. Move to the next chapter when the completion criteria are met.
